## 已接入

- 保留独立弹窗，以批次为一行，分为当前任务和历史记录；摘要保留任务名称、对象/范围、状态。异常和待处理项目优先显示，成功项目和日志折叠。
- 导入选择及同名处理在任务行内完成；支持跳过、覆盖、重命名。折叠、切换标签以及关闭窗口后保留当前选择。
- 更新技能仓库的检查、审阅、同步共用一个批次。仓库和技能/文件变化逐层展开。删除确认绑定所选快照；快照改变后必须重新确认。
- 刷新仓库信息单独呈现，同时覆盖批量和单仓刷新。操作范围在任务创建时记录，避免根据数量推断全库或所选。
- 重试失败项、停止批次、继续未完成项复用现有队列；成功任务保留到收起后进入历史，避免操作中跳走。
- AI 生成备注和解释不出现在任务列表、历史及计数中；原执行逻辑和应用退出保护保留。
- 仓库快照与导入选择提交在 store 内校验，防止旧快照、未确认删除或过期导入选择继续执行。
