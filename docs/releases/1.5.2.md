# Arsenal 1.5.2

发布日期：2026-10-26。

## 大备份导入

修复大备份在 WebView 和后台之间以完整数字数组往返传输、导致内存显著放大的实现。WebDAV 现在由后台流式下载并直接恢复，本地导入使用原生文件选择器，只向后台传递路径。界面显示下载、校验和恢复进度，不接收备份载荷。

ZIP 条目在磁盘临时目录内逐个校验和暂存，不再保留全部解压文件及 Base64 副本。完整下载、CRC、路径与大小校验通过后才进入恢复。下载中断或归档校验失败会清理临时文件，不启动恢复。

输入 ZIP 上限 1 GiB、解压总量上限 16 GiB、最多 100000 条目；manifest 与独立 JSON 备份上限 128 MiB。请在配置目录和资源库所在磁盘预留下载、解压及目录替换所需空间。

WebDAV 恢复范围仍为资源库与集合，本地导入仍支持完整备份。原有备份格式不变；本次不重构导出、上传的后台内存使用，也不将整份备份恢复改为全局事务。校验通过后的实际写入阶段若失败，仍可能已完成部分恢复。

## 验证与升级

- 前端全量 941 项、Rust 全量 649 项测试通过；18 项按原设置忽略。
- 800 MiB 合成 ZIP 另行显式通过了真实 HTTP 下载、后台恢复和逐块内容核验。单独 Windows debug 后台测试进程的峰值工作集约 21.5 MiB；这不是 macOS 整个应用的内存上限。
- Windows 正式程序构建通过。跨平台打包及 macOS 启动检查由发布工作流执行；macOS 使用实际大备份的恢复和界面响应仍需复测，实际备份完整性尚未核实。
- 同步更新设置页显示版本和 Linux 包版本元数据。

升级前从托盘菜单选择“退出”，并备份现有配置与资源库。便携版仅替换程序，不用发行包的默认配置覆盖现有 `.arsenal`。既有 Arsenal 命名规则保持不变。
