# Arsenal 1.5.0

发布日期：2026-10-25。

## 窗口与托盘

主窗口保存并恢复大小、位置与最大化状态，窗口状态保存在当前 `.arsenal/window-state.json`。关闭主窗口仅隐藏到托盘，不停止任务；左键托盘图标还原窗口，右键菜单提供“显示主窗口”“退出”。有任务执行时，明确退出仍显示原有确认提示；取消后任务继续。启动时不恢复隐藏或最小化状态，避免窗口无法找到。

## 任务与更新

任务窗口的“当前任务”“历史记录”“日志”位于同一标题栏。仓库更新审阅使用左侧筛选栏，区分待处理、可同步、需确认、需重查、已完成和全部；全选只作用于可同步仓库。检查中的排队项不计入需重查。

风险提示与确认图标放在“核对风险”标题行。确认后仓库显示“已确认”、选入同步并自动折叠；新快照不沿用旧确认。检查范围由仓库与保留的导入选择决定，同仓库的其他目录不等于其他仓库；需要重新选择来源变体时使用重新导入。

任务失败显示已识别的原因和建议，统一日志保留对应结果。未知异常标明操作与诊断代码，不把原因猜成配置错误。旧记录若未保存原始原因，只能通过再次执行取得新的诊断。写入成功但列表刷新失败时保留成功结果并提示刷新警告。

## 导入、删除与笔记

导入去重比较技能包内容，更新保留所选来源变体；支持分类目录和来源移动，排除脚本测试夹具及不带技能元数据的普通小写说明文档。已安装根技能移动后保留其更新范围，不自动引入仓库中的示例技能。

回收站保存可恢复的删除记录，支持按仓库和技能名称搜索。重新导入可再次选择上游技能；清空回收站会永久删除相应恢复数据。

界面与插件显示 Arsenal 名称。后续开发的命名重置规则见[命名规范](../design/naming.md)；本页历史版本的下载内容以发布标签为准。

## 升级

从发布附件选择系统和架构对应的包。升级前从托盘菜单选择“退出”并备份，关闭窗口只会隐藏程序。Windows 便携版本仅替换程序，保留原有 `.arsenal`；不要使用发行包中的默认配置覆盖已有配置。Obsidian 插件更新仍安装到 `.obsidian/plugins/arsenal-link/`。

演示截图使用虚构数据与当前 React 组件，不代表已执行远程导入或同步，复现方式见[截图说明](../screenshots/README.md)。跨平台包由发布工作流生成；构建成功与真实平台的完整桌面交互验收分别记录。
